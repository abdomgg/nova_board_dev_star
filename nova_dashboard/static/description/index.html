Frequently asked questions

Do the widgets update in real time?

Yes. Every widget reads live from the underlying Odoo model, with an optional auto-refresh interval per dashboard.

Do I need an API key to use NovaMind?

No — the built-in offline brain handles dashboard building, restyling and Q&A out of the box. If you'd rather route it through your own account, add an OpenAI-compatible key and endpoint via System Parameters and NovaMind switches over.

Does forecasting or anomaly detection need a Python package I don't have?

No. NovaBoard ships zero external Python dependencies — forecasting and anomaly detection run on built-in logic, so it installs on any Odoo 18 instance without extra pip packages.

Can I move a dashboard between databases?

Yes, export it to JSON from Board Info or Control Center and import it on the target database.
